# QA de paginación

- [ ] `page=0`, `page=-1`, no numérica, gigante y límites de tamaño.
- [ ] Cambio filtros o search reinicia página.
- [ ] Back/forward restaura estado URL.
- [ ] Requests tardíos no reemplazan filtro actual.
- [ ] Borrar último elemento no deja página fantasma.
- [ ] Orden de datos estable; backend valida sort.
- [ ] Loading vs empty vs filtered-empty vs error.
- [ ] Responsive, teclado, screen reader, foco y `aria` de controles.
- [ ] Cache por organización y usuario, invalidación tras mutación.
- [ ] Cursor no fabrica total ni salto de página; selección masiva explícita.
