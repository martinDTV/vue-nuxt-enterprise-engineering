# Definition of Done — Vue/Nuxt Enterprise

- [ ] Revisadas versiones de Nuxt/Vue, lockfile y convenciones.
- [ ] UI funcional en viewport desktop/móvil y navegación con teclado.
- [ ] Todos los estados (loading, empty, error, forbidden, success) definidos.
- [ ] Errores HTTP y validación correctamente tipados y manejados.
- [ ] Permisos validados en backend; frontend no se trata como barrera de seguridad.
- [ ] SSR sin estado global compartido ni hydration mismatch.
- [ ] No tokens ni PII en URL, payload innecesario, caché pública, logs o analytics.
- [ ] URL, paginación, filtros, sorting y cambio de organización comprobados.
- [ ] Pruebas focalizadas relevantes y E2E en flujo crítico.
- [ ] Typecheck, lint, build, tests y métricas realmente ejecutados y reportados.
- [ ] No nuevas dependencias sin justificación y lockfile revisado.
- [ ] Documentación/contratos actualizados, rollout, rollback y riesgos pendientes.
